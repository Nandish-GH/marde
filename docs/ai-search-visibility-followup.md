## Verification and measurement

The scanner's HTML stripping procedure confirms the business summary appears within the first 8,000 characters used by its profiler. Public verification checks the existing live routes in HTML/Markdown, Markdown aliases, discovery files, 404s and canonical redirects; those live checks do not establish that local changes have been deployed.

The [scanner crawler](https://github.com/kjagsadvisors/aisearchhelpers/blob/main/src/lib/crawl.ts) reads homepage headings, metadata, root JSON-LD types and text, plus the sitemap; it does not inspect every linked page. Its [scan pipeline](https://github.com/kjagsadvisors/aisearchhelpers/blob/main/src/lib/scan.ts) profiles the business, generates buying queries, asks model-backed web-search questions and composes the score. A complete equivalent rerun requires configured Anthropic and optional OpenRouter access.
